## Heart Disease Classification

This project focuses on predictive modeling for heart disease classification using the Naive Bayes algorithm. It demonstrates a complete machine learning workflow, from data preparation and exploration to model training, evaluation, and interpretation

## Project Structure
```
.
├── artifacts/                 # Plots directory
├── README.md
├── implementation.ipynb       # Full implementation: data prep, EDA, modeling
├── report.ipynb               # Analysis, results, and discussion
└── processed.cleveland.data   # Source dataset
```

## Result

The Naive Bayes model demonstrated competitive performance in heart disease classification, indicating that probabilistic classifiers can be effective and quite robust when applied to structured clinical datasets with relatively simple assumptions.

The results show that, despite its simplicity, Naive Bayes can capture meaningful patterns in medical data and serve as a strong baseline for classification tasks. However, my project is intended strictly for educational and analytical purposes, and the model like that would never be used for real-world clinical decision-making without extensive validation, robustness, domain expert review, and compliance with medical standards
